Audio_Init

Initialise the audio library with sensible defaults.

Syntax

bool Audio_Init(void);

Return Value

Returns true on success, or false on failure.

Remarks

The current defaults are: 44100 hz, 2 channel, 32-bit floating point audio.

Channel_Play

Bind a buffer to the channel and play it, resampling to the default device format.

Syntax

int Channel_Play(int channel_index, Sound_Buffer *buffer, int loop_count);

Return Value

Returns the channel index on success, or -1 on failure.

Remarks

This function expects that the buffer data is in some sort of decodable container (.WAV, .MP3, ...). If you want to play raw, uncompressed data, then call Channel_PlayEx() with raw_audio set to true. If loop_count is negative, then the buffer will loop infinitely. Pass -1 as the channel_index to automatically find a free channel.

Channel_PlayEx

Bind a buffer to the channel and play it, resampling to the default device format.

Syntax

int Channel_PlayEx(int channel_index, Sound_Buffer *buffer, int loop_count, int sample_rate, int channels, ma_format format, bool raw_audio);

Return Value

Returns the channel index on success, or -1 on failure.

Remarks

If any combination of sample_rate, channels, or format are non-zero, then the library will resample the buffer to that specification, and then again to the output device format. Otherwise, the function behaves identically to Channel_Play. If raw_audio is true, then this indicates that the buffer contains uncompressed raw audio data. In this case, sample_rate, channels, and format _must_ be specified. If loop_count is negative, then the buffer will loop infinitely. Pass -1 as the channel_index to automatically find a free channel.
